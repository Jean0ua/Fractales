# Fractals — Génération de fractales en Python

Ce projet a pour objectif de générer et de visualiser des fractales à l’aide de Python. Il permet d’explorer la beauté des structures mathématiques, caractérisées par des motifs complexes qui se répètent à différentes échelles.

## Fonctionnalités

- Génération de fractales à partir d’algorithmes mathématiques.
- Visualisation graphique des structures fractales.
- Exploration de motifs géométriques et de formes complexes.
- Code conçu pour faciliter l’expérimentation et l’apprentissage des mathématiques et de la programmation.

## Technologies

- **Python** — langage principal du projet.
- **Matplotlib / NumPy** — visualisation et calcul numérique, si utilisés dans le projet.

## Objectif

L’objectif est de découvrir les fractales, de comprendre les algorithmes qui permettent de les générer et d’expérimenter avec différentes représentations visuelles.
